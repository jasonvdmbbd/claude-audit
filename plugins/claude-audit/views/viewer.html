Open an audit database

Pick the SQLite file your machine's Claude Code audit logger writes, or drag it anywhere onto this page.

It normally lives at ~/.claude/audit/audit.db — one file, shared by every workspace on this machine.

You only need audit.db. The audit.db-wal and audit.db-shm sidecar files can be ignored — though turns written very recently may still be sitting in the WAL and will appear once SQLite checkpoints them. Nothing is uploaded: the file is read locally in your browser.
